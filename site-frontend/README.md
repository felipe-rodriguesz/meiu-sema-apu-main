# Painel SEMA

Pontos, pedidos, recebimento, correções e relatórios/CSV. React, TypeScript e Vite; Node 24.

Configure `.env` a partir de `.env.example` e mantenha a API disponível. Instruções completas e variáveis estão em [OPERAÇÃO](../docs/OPERACAO.md).

```sh
npm ci
npm run dev -- --port 5173
```

Use `npm run build` para compilar. Testes e limites da análise de código estão em [ENTREGA](../docs/ENTREGA-FASEIV.md). Contratos: [API](../docs/API.md).
